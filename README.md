# Glossolalia Explorer

Experimental phonetic transcription of audio with Allosaurus, with a Windows batch interface and custom phoneme inventories.

Инструмент для исследования звучания глоссолалии и других аудиозаписей. Преобразует аудио в WAV, запускает фонетическое распознавание и собирает таймстампы, top-3 вариантов и оценки модели в один TXT.

**Пять пользовательских профилей — экспериментальные и неофициальные.** Они ограничивают выбор звуков универсальной модели. Программа не устанавливает язык записи, не переводит речь и не подтверждает интерпретации её содержания.

## Возможности

- Массовое выделение файлов через Ctrl/Shift или передача нескольких путей командой.
- 16 режимов: универсальный IPA, 10 встроенных языковых наборов и 5 пользовательских.
- Галилейский арамейский, мандейский арамейский, классический сирьяк, койне, латынь.
- Проверка доступности режимов и звуков до распознавания.
- Отдельная отметка **«ЭКСПЕРИМЕНТАЛЬНЫЙ, НЕОФИЦИАЛЬНЫЙ ПРОФИЛЬ»** в консоли и TXT.
- Повторное использование одноимённого WAV.
- Файл результата с исходным именем: `запись.txt`. При совпадении: `запись_NEW.txt`, затем `запись_NEW_NEW.txt`.
- Ошибка одного режима не останавливает остальные; ошибка конвертации не останавливает очередь.
- Большая зелёная галочка после сохранения TXT; отчёт автоматически не открывается.

## Требования и установка

Windows, PowerShell 5.1 или 7, Python 3.12, FFmpeg в PATH. Рабочая связка проверена с Allosaurus 1.0.2 и моделью uni2005. Другие версии Python не проверены.

```powershell
git clone https://github.com/kva4991/glossolalia-explorer.git
cd glossolalia-explorer
powershell -NoProfile -ExecutionPolicy Bypass -File .\Setup.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\Start-Glossolalia.ps1 -CheckOnly
```

`Setup.ps1` создаёт локальное окружение `.venv`, устанавливает зависимости из PyPI и загружает модель uni2005 из источника Allosaurus. Нужны интернет и место для PyTorch и модели. FFmpeg установите отдельно из [официальных источников](https://ffmpeg.org/download.html), затем откройте новую консоль. Проверка доступности: `ffmpeg -version`.

При наличии своего Python можно выполнить `Setup.ps1 -PythonPath 'D:\Python312\python.exe'`. Политика выполнения в командах выше применяется только к запускаемому процессу.

Уже установленное окружение также подходит: передайте `-PythonPath`. Без параметра программа ищет сначала `.venv\Scripts\python.exe`, затем прежнее окружение `allosaurus-env` в домашнем каталоге пользователя.

## Запуск

Дважды щёлкните `Start.cmd`: выберите файлы, дождитесь обработки и галочки. Окно останется открытым для чтения сообщений. По умолчанию выбор начинается в родительской папке проекта; в исходном расположении это папка `Глоссариа`.

В PowerShell:

```powershell
.\Start-Glossolalia.ps1
.\Start-Glossolalia.ps1 -InitialDirectory 'D:\Audio'
.\Start-Glossolalia.ps1 -AudioPath 'D:\Audio\1.m4a','D:\Audio\2.wav'
.\Start-Glossolalia.ps1 -AudioPath 'D:\Audio\1.wav' -Modes ipa,galilean,mandaic
.\Start-Glossolalia.ps1 -CheckOnly
```

Параметры `-PythonPath` и `-FfmpegPath` принимают пути к нужным исполняемым файлам. `-Model` выбирает уже установленную модель, по умолчанию `uni2005`. Неизвестный режим в `-Modes` считается ошибкой.

Рядом с `1.m4a` создаются `1.wav` (моно, 16 кГц, PCM 16 bit) и `1.txt`. Если WAV уже существует, он используется как есть. Для входного WAV рекомендуется такой же формат; программа не исправляет существующий WAV автоматически. Существующие TXT сохраняются.

Галочка означает сохранение отчёта. Состояние отдельных режимов и их ошибки указаны внутри; галочка не подтверждает точность распознавания.

## Профили и результаты

Настройки режимов находятся в [languages.json](languages.json), наборы звуков — в пяти TXT в корне проекта. Их текущий состав сохранён из пользовательских файлов. [Описание профилей](README-profiles.md) содержит число звуков, известные ограничения и происхождение.

Файлы WAV, аудиозаписи, результаты TXT и окружение Python исключены из Git. Полные расшифровки в других форматах храните в `private/` или `results/`; модели в репозиторий не включаются. Исключения для пяти профилей и `requirements.txt` заданы явно. Не используйте имена файлов профилей для аудиозаписей внутри корня проекта: одноимённый TXT уже занят.

Оценки `p` относятся к выходу модели в выбранном наборе, а не к вероятности языка. Таймстампы приблизительны; паузы определяются по промежуткам между распознанными звуками. Пустой результат сам по себе не доказывает тишину. См. [методику](docs/METHODOLOGY.md).

## Разработка и проверка

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tests\Test-Project.ps1
pwsh -NoProfile -File .\tests\Test-Project.ps1
```

Проверки без Allosaurus используют управляемые ответы внешних команд: массовую обработку, ошибки, коллизии имён, маркировку профилей и top-3. GitHub Actions запускает их в обеих версиях PowerShell.

[Проверка реального распознавателя](tests/Smoke-Allosaurus.ps1) создаёт синтетический WAV во временной папке и запускает IPA и пять пользовательских режимов. Требует установленного Allosaurus и FFmpeg; это проверка подключения, не качества языка.
