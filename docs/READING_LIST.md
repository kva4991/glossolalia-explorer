# Кандидаты для исследовательской библиотеки

Это перечень из предоставленного автором `LIBRARY_CATALOG.md` (получен 26.09.2026), а не список уже имеющихся или проверенных книг. Точные издания, ссылки, цитаты и применимость каждого комментария предстоит сверить до использования в разборе записи. Религиозный комментарий может помогать интерпретации, но не устанавливает произнесённые фонемы или перевод молитвы.

## Еврейские тексты и языковые справочники

| Кандидат из источника | Возможная задача |
| --- | --- |
| Раши, комментарии к Торе и Псалмам | Сопоставить историческое толкование конкретного стиха. |
| Давид Кимхи (Радак), «Сефер ха-шорашим» и комментарии к Псалмам | Проверить написание, форму и значения предполагаемого еврейского корня. |
| Авраам ибн Эзра, комментарии к Торе и Псалмам | Сравнить контекстуальные толкования. |
| Моше бен Маймон (Маймонид), «Мишне Тора»; мидраши | Уточнять конкретные религиозные понятия только по проверенному месту текста. |
| Еврейские словари, указатели конкорданции и библиотека Sefaria | Найти исходный текст и варианты написания, затем проверить первоисточник. |

## Христианские толкования

| Кандидат из источника | Возможная задача |
| --- | --- |
| Ефрем Сирин и Феодорит Кирский | Сверить толкование конкретных библейских мест и перевод издания. |
| Ориген и святитель Филарет (Дроздов) | Сопоставить разные традиции толкования без приписывания им анализа этих записей. |
| Александр Мень, Николай Глубоковский, Андрей Кураев | Использовать только с точной атрибуцией и контекстом; это разные авторы и жанры. |

Для каждого заимствованного утверждения нужны автор, произведение, место, издание или стабильная ссылка и дата проверки. Список не задаёт обязательной закупки либо скачивания. Кандидаты `דבר`, `דרך`, `פדה`, `דרור`, `מעיל`, `עד`, `שירו` из [второй песни](transcriptions/T00020.md) следует сначала проверить по грамматике и записи, а затем уже сопоставлять с толкованиями.
