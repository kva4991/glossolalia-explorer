# Проверка версии 0.1.0

Дата: 22.09.2026. Среда: Windows, PowerShell 5.1.26100.6725 и 7.6.5, Python 3.12.10, Allosaurus 1.0.2, uni2005.

## Выполнено

- Проверка синтаксиса PowerShell-файлов.
- Пакетные тесты в PowerShell 5.1 и 7: 16 режимов, пять пользовательских профилей, три сохранённых отчёта, 48 попыток распознавания через управляемые ответы.
- Повторное использование WAV, коллизии TXT с _NEW, продолжение после ошибки конвертации или режима, очистка временных файлов, отсутствие готового WAV после незавершённой конвертации.
- Разбор top-3, случая без вероятности и пустого результата; отметки неофициальных профилей и неподдерживаемых символов.
- Проверка UTF-8/BOM, пустых строк, повторов, неизвестных символов и регистрозависимого сравнения I/i.
- Проверка -CheckOnly и ошибочных настроек режима/списка языков.
- Реальный запуск универсального IPA и пяти пользовательских профилей на синтетическом WAV в PowerShell 7 и 5.1.
- Сверка контрольных сумм пяти исходных пользовательских профилей: состав и байты сохранены.
- Проверка исключений Git для аудио, полных результатов и локальной резервной копии.

## Ограничения

Установка Setup.ps1 с нуля в чистое окружение не выполнялась: для реальных запусков использовано уже работающее окружение. Пакет Allosaurus закреплён, все транзитивные зависимости не зафиксированы.

Диалог массового выбора в этой сессии вручную не открывался; проверен путь передачи списка файлов и сохранена настройка Multiselect.

Интеграционный тест проверяет подключение и завершение режимов. Точность фонетической транскрипции, идентификация языков, переводы и исторические реконструкции на размеченных записях не оценивались.
