## Разработчику и ИИ-агенту

1. Прочитайте [правила проекта](../AGENTS.md) и [точку входа в разработку](DEVELOPMENT.md).
2. По [карте меток](dev/tag-map.md) найдите документ, который определяет затрагиваемое поведение.
3. Проверьте [сопутствующие изменения](CHANGE_IMPACT.md); для нового устойчивого решения используйте [ADR](architecture/decisions/README.md).
4. Обновите нужный документ по [стандарту документации](DOCUMENTATION.md), затем выполните [проверки](TESTING.md).

[Журнал изменений](../CHANGELOG.md) описывает историю. [Отчёт о проверке](VALIDATION.md) хранит результаты 0.1.0 и отдельное дополнение о профиле от 23.09.2026, а не обещание проверки любой следующей версии.

## Полный каталог

[Реестр документов](dev/documentation.json) — источник списка страниц, их назначения, статуса и устойчивых меток. [Карта меток и каталог](dev/tag-map.md) строятся из него автоматически.

Статус «актуальный документ» означает поддерживаемую инструкцию; он не подтверждает лингвистическую точность. Статусы примеров и личных гипотез указаны внутри соответствующих страниц.
