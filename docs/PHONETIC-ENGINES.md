# Установка и запуск ZIPA и Wav2Vec2Phoneme

Два отдельных скрипта обрабатывают выбранные записи локально и сохраняют TXT рядом с исходным файлом. Для обычного запуска используйте [Start-ZIPA.cmd](../Start-ZIPA.cmd) или [Start-W2V2.cmd](../Start-W2V2.cmd): окно останется открытым после завершения.

| Скрипт | Модель | Результат для 4.wav |
| --- | --- | --- |
| [Start-ZIPA.ps1](../Start-ZIPA.ps1) | ZIPA Small CRCTC NS, ONNX FP32 | 4 (ZIPA).txt |
| [Start-W2V2.ps1](../Start-W2V2.ps1) | Wav2Vec2 XLSR-53 с фонетическими метками | 4 (W2V2).txt |

Можно выделить несколько файлов через Ctrl/Shift. Начальная папка — родительская папка проекта, в исходной установке `C:\Users\User\Documents\Глоссариа`. После сохранения каждого TXT выводится большая зелёная галочка; файлы автоматически не открываются.

Оба запуска теперь вставляют короткие, средние и длинные паузы внутрь транскрипций. [Общий запуск](PAUSES.md) создаёт также отдельный универсальный результат Allosaurus — три TXT на запись.

## Установка на Windows

Нужны Windows, Python 3.12, PowerShell 5.1 или 7, FFmpeg в PATH и интернет для первой установки. Работа выполняется на CPU; CUDA и видеокарта NVIDIA не требуются. Предусмотрите несколько гигабайт для двух окружений, моделей и кеша pip.

Команды запускаются из корня проекта. На компьютере разработчика:

```powershell
Set-Location -LiteralPath 'C:\Users\User\Documents\Глоссариа\project'
powershell -NoProfile -ExecutionPolicy Bypass -File .\Setup-PhoneticEngines.ps1 -PythonPath 'C:\Users\User\AppData\Local\Programs\Python\Python312\python.exe'
```

На другом компьютере можно опустить `-PythonPath`: установщик вызовет `py -3.12`. FFmpeg устанавливается отдельно; проверка доступности — `ffmpeg -version`.

[Установщик](../Setup-PhoneticEngines.ps1) последовательно:

1. Создаёт два независимых venv в `%USERPROFILE%\glossolalia-engines\zipa\.venv` и `%USERPROFILE%\glossolalia-engines\w2v2\.venv`.
2. Устанавливает CPU-сборку PyTorch 2.8.0 с `https://download.pytorch.org/whl/cpu`; для ZIPA также torchaudio 2.8.0.
3. Устанавливает пакеты из [requirements/zipa.txt](../requirements/zipa.txt) и [requirements/w2v2.txt](../requirements/w2v2.txt) через PyPI и выполняет `pip check`.
4. Загружает только перечисленные в [engines.json](../engines.json) файлы закреплённых ревизий с Hugging Face в каталог `model` соответствующего движка.
5. Записывает `model\installation.json`: источник, ревизию, SHA-256 каждого файла и версии всех установленных Python-пакетов.
6. Устанавливает общий Silero VAD по закреплённой ревизии и SHA-256; новые Python-пакеты не нужны.
7. Загружает каждую модель и детектор пауз, выполняет пробный расчёт на коротком синтетическом сигнале.

Успех — сообщение «Установка завершена» и код 0. Исходники проекта, записи и прежнее окружение Allosaurus установщик не меняет. Повторный запуск использует уже скачанные файлы и приводит прямые зависимости к указанным версиям; транзитивные версии фиксируются в квитанции конкретной установки, но не заблокированы общим lock-файлом.

Для отдельного движка или другого места хранения:

```powershell
.\Setup-PhoneticEngines.ps1 -Engine zipa
.\Setup-PhoneticEngines.ps1 -Engine w2v2 -RuntimeDirectory 'D:\GlossolaliaModels'
```

Если изменили каталог установки, передавайте такой же `-RuntimeDirectory` при распознавании. Окружения и веса не публикуются вместе с проектом.

## Как выполнена установка 22.09.2026

Установлено на Windows с Python 3.12.10, процессором AMD Ryzen 5 4500U и запуском моделей на CPU. Использован базовый Python `C:\Users\User\AppData\Local\Programs\Python\Python312\python.exe`; окружения находятся в `C:\Users\User\glossolalia-engines`.

| Компонент | Закреплённая версия |
| --- | --- |
| torch / torchaudio для ZIPA | 2.8.0+cpu / 2.8.0+cpu |
| onnxruntime / lhotse | 1.22.1 / 1.33.0 |
| torch / transformers для W2V2 | 2.8.0+cpu / 4.57.6 |
| numpy / soundfile | 2.2.6 / 0.13.1 |
| huggingface-hub / truststore | 0.36.0 / 0.10.4 |

ZIPA: `anyspeech/zipa-small-crctc-ns-700k`, ревизия `86ce6920bcf23f27f449fd21b77b9886804bd734`; используется `model.onnx` FP32, без понижения точности до INT8.

W2V2: `facebook/wav2vec2-xlsr-53-espeak-cv-ft`, ревизия `2c733782da5604684829819a5eb744c193fe9398`; используются `pytorch_model.bin`, конфигурация, обработчик аудио и словарь меток.

При первой загрузке большого файла W2V2 возникла ошибка цепочки сертификатов CDN Hugging Face. В загрузчик добавлен `truststore`, использующий системное хранилище сертификатов Windows; проверка TLS остаётся включённой. После изменения полный установщик выполнен повторно.

Шаги загрузки и проверок воспроизводятся командой выше. Токены Hugging Face не требуются: обе модели публичные, загрузчик использует `token=False`. Распознавание после установки читает локальные модели и не отправляет аудио в сеть.

## Запуск и имена результатов

Из корня проекта в PowerShell:

```powershell
.\Start-ZIPA.ps1
.\Start-W2V2.ps1
.\Start-ZIPA.ps1 -AudioPath 'D:\Audio\1.wav','D:\Audio\2.m4a'
.\Start-W2V2.ps1 -AudioPath 'D:\Audio\1.wav' -RuntimeDirectory 'D:\GlossolaliaModels'
.\Start-ZIPA.ps1 -CheckOnly
.\Start-W2V2.ps1 -CheckOnly
```

Оба скрипта принимают `-Profile` (необязательный [пользовательский набор](LANGUAGE-PROFILES.md)), `-AudioPath`, `-InitialDirectory`, `-RuntimeDirectory`, `-PythonPath`, `-FfmpegPath` и `-CheckOnly`. Для массива файлов используйте вызов из PowerShell, как в примере; команда `powershell.exe -File` не является удобным способом передать массив путей. `-CheckOnly` проверяет загрузку и пробный расчёт модели, не создавая расшифровок.

| Ситуация | Поведение |
| --- | --- |
| Уже есть 4 (ZIPA).txt | Создаётся 4_NEW (ZIPA).txt, затем 4_NEW_NEW (ZIPA).txt |
| Есть результат другой модели | Он сохраняется; имена ZIPA и W2V2 не конфликтуют |
| В исходном имени есть пробелы, двойные точки или невидимые символы | Основа имени сохраняется |
| Уже есть одноимённый WAV | Он используется без перезаписи |
| WAV ещё нет | FFmpeg создаёт mono PCM 16 bit 16 кГц через временный файл |
| WAV имеет другую частоту или несколько каналов | Для модели FFmpeg декодирует моно 16 кГц в память; WAV на диске не меняется |
| Один файл не распознаётся | Очередь продолжается; для неудачного файла TXT не создаётся, итоговый код ненулевой |

TXT записывается в UTF-8 без BOM. В формате 2 находятся имя исходника, модель и ревизия, длительность, транскрипция с паузами, исходная последовательность без вставок и части записи. Пороги и модель пауз указаны в заголовке. Галочка означает успешное сохранение результата конкретного файла, а не подтверждение перевода.

## Обработка и границы результата

Модель загружается один раз на очередь. Записи обрабатываются окнами до 30 секунд с контекстом до 2 секунд с каждой стороны; перед CTC-декодированием контекстные кадры отбрасываются. Это ограничивает размер модельного расчёта, но декодированное аудио одного файла хранится в памяти целиком.

Сжатие CTC удаляет соседние повторы одной метки и служебную пустоту; повтор после пустоты сохраняется. Приблизительное время кадра метки используется для вставки пауз; служебная пустота не считается тишиной. Времена в разделе частей записи относятся к окнам и не являются границами отдельных фонем или слов. Соответствие кадров времени приблизительное; результат у стыка окон требует ручной сверки. Детектор, алгоритм и ограничения описаны в [инструкции пауз](PAUSES.md).

По умолчанию языковой профиль не применяется. Параметр `-Profile author-semitic` включает [ограничение допустимых меток](LANGUAGE-PROFILES.md) до CTC-декодирования и сохраняет отдельный TXT с идентификатором профиля в имени. Словарь слов и готовые предполагаемые фразы моделям не передаются. W2V2 запускается как акустическая CTC-модель, без eSpeak и преобразования заранее известного текста в фонемы. Метки обеих моделей сохраняются как выданы: их наборы и способ записи диакритик различаются. Знак `▁` у ZIPA сохраняется как метка границы, а не как доказанная граница слова.

Готового перевода, определения языка и оценок точности отдельных фонем эти два скрипта не создают. Пустой выход не доказывает тишину. Старые 16 режимов Allosaurus доступны отдельно; его отчёты не заменяются.

## Проверки и типичные ошибки

Команды автоматических тестов и результаты установки приведены в [TESTING](TESTING.md). Проверка загрузки подтверждает работоспособность движка, а не лингвистическую точность.

- «Python не найден»: выполните установщик или передайте правильный `-RuntimeDirectory` / `-PythonPath`.
- «Ревизия модели отличается»: повторите установку по текущему `engines.json`.
- FFmpeg отсутствует: установите его, откройте новую консоль либо укажите полный `-FfmpegPath`.
- Ошибка TLS: проверьте системную цепочку доверия, прокси и доступ к Hugging Face/CDN; не отключайте проверку сертификатов.
- Недостаточно памяти: завершите другие тяжёлые процессы и обрабатывайте меньшие файлы; на CPU продолжительность зависит от записи и компьютера.

## Источники и условия

Способ вычисления признаков ZIPA сверялся с [официальным inference](https://github.com/lingjzhu/zipa/tree/ed94d27fba14fe5ad0e289227d69d7ccc8a2eee5/inference): Fbank с 80 фильтрами, `dither=0.0`, `snip_edges=False` и CTC ONNX. Для W2V2 использована [карточка модели Meta](https://huggingface.co/facebook/wav2vec2-xlsr-53-espeak-cv-ft). Источники проверены 22.09.2026.

Веса и сторонние пакеты сохраняют собственные условия; см. [THIRD_PARTY](../THIRD_PARTY.md). Устройство отдельных окружений описано в [ADR-0004](architecture/decisions/0004-phonetic-engines.md).
