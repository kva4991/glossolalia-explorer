# ADR-0005: Три транскрипции с общими паузами

- Статус решения: Принято
- Дата: 22.09.2026
- Состояние реализации: общий запуск трёх локальных моделей и VAD-разметка
- Связи: [паузы](../../PAUSES.md), §pauses, §engines, §lexicon, §testing

## Контекст

Пользователь запросил три итоговых файла от трёх моделей с короткими, средними и длинными паузами внутри текста. Между фонетическими выходами есть расхождения; пустые CTC-кадры не дают самостоятельного измерения отсутствия речи.

## Решение

Использовать закреплённую Silero VAD для анализа одинакового аудио всех трёх движков, а временные метки распознавателей — для приблизительного места вставки. Не удалять фонетические метки на спорных участках. Сохранять исходную последовательность для проверки и классифицировать длительности по настраиваемым порогам.

Основной Start.cmd вызывает Start-AllModels.ps1. Allosaurus в сравнительном режиме выдаёт универсальный IPA; ZIPA и W2V2 сохраняют свои метки. На каждую запись создаются три TXT с суффиксами моделей и правилом _NEW. Окружения остаются раздельными, Allosaurus запускается внешним процессом. Старый сценарий с 16 профилями сохраняется отдельно.

## Последствия

Общий детектор даёт сопоставимые интервалы пауз, но не три независимые оценки их наличия. Ошибки VAD и временной привязки явно отделяются от транскрипции. Словарь прекращает подбор последовательностей через новые маркеры пауз. Детектор работает локально; закреплённые веса проверяются по SHA-256.

Решение дополняет [ADR-0004](0004-phonetic-engines.md), изменяя основной запуск и формат результата, и сохраняет [границы исследования](0001-phonetic-boundary.md). Проверки включают синтетические интервалы, сохранность фонем, реальные модели и хеши исходных файлов; качество лингвистических выводов ими не доказывается.
