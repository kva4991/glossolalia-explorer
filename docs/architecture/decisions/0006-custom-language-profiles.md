# ADR-0006: Пользовательские наборы для трёх моделей

- Статус решения: Принято
- Дата: 23.09.2026
- Состояние реализации: Необязательный профиль декодирования в локальных Windows-запусках
- Связи: [профили](../../LANGUAGE-PROFILES.md), §languageprofiles, §engines, §profiles, §lexicon

## Контекст

Пользователь предоставил текстовые фонетические шаблоны и попросил использовать их как ещё один язык. Установленные ZIPA/W2V2 не принимают инструкции на естественном языке; у Allosaurus есть механизм языкового набора. Ожидаемые слова и исторические гипотезы не являются обучающими аудиоданными.

## Решение

Явный параметр `-Profile` выбирает версионируемый JSON с допустимыми фонетическими формами и представлениями в словаре каждой модели. Для Allosaurus создаётся временный набор, для ZIPA/W2V2 применяется маска перед выбором метки и CTC. Пустота и служебная граница сохраняются; составные метки разрешаются только по явной конфигурации. Никакие новые пакеты или веса не устанавливаются.

По умолчанию ограничения отсутствуют. Отчёты профиля имеют отдельные имена, явный статус и SHA-256 конфигурации. Исходные авторские тексты остаются справочным материалом; готовые слова не вставляются в фонетическую последовательность.

## Последствия

Профиль ограничивает набор, но не обучает новый язык, порядок звуков или позиционные правила. Компоненты составных представлений могут возникать независимо. Недоступные формы перечисляются; запрет правильной метки способен ухудшить распознавание.

Существующий указатель повторов пропускает результаты с профилем. Это сохраняет независимый обычный результат при выборе последнего отчёта модели и не смешивает разные условия декодирования.

## Проверка и пересмотр

Нужны тесты маски до CTC, служебных меток, представления составных форм, имён, передачи профиля через PowerShell и словарного исключения. Реальный CheckOnly и обработка записи подтверждают совместимость движков и сохранность аудио, но не историческую или фонетическую точность.

Отдельный языковой декодер, поиск повторов по профилю, обучение модели или поддержка Whisper требуют самостоятельной реализации и проверки.
