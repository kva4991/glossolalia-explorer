# ADR-0002: Передача Android-результата во внешний чат

- Статус решения: Принято
- Дата: 22.09.2026
- Состояние реализации: план; приложение не создано
- Связи: §android

## Контекст и варианты

Обсуждались встроенный чат через API и передача подготовленного текста в установленное приложение. Владелец выбрал ChatGPT/Gemini через «Поделиться» и отдельно поручил пока подготовить только план.

## Решение

Будущее приложение объединяет подходящий промпт и фонетическую расшифровку в одно сообщение, показывает его пользователю и предлагает системный обмен текстом. Резервный путь — копирование.

## Последствия

Получатель управляет дальнейшей отправкой; установка системного промпта или выбор конкретного разговора не гарантируются. Совместимость проверяется на реальных версиях внешних приложений. Подробный сценарий и приёмка находятся в [Android-плане](../../ANDROID.md).

Место распознавания — телефон либо компьютер/сервер — не выбрано. Этот ADR не вводит сервер, API-провайдера, мобильный runtime или готовый APK.

## Проверка и пересмотр

Пока проверяются только согласованность плана и документация. Проверка диктофона и обмена на телефоне появится вместе с реализацией. Изменение способа работы с чатом оформляется отдельным решением.
