| Whisper | В текущем проекте нет установленного обработчика Whisper | Файл сохранён для последующей настройки и сравнения |

Перенос файлов в проект сам по себе не меняет декодирование. Обычный запуск [трёх моделей](../../../docs/PAUSES.md) сохраняет акустические результаты с общей разметкой пауз. Шаблоны можно использовать при последующем сопоставлении этих результатов с авторскими гипотезами; такое сопоставление следует подписывать отдельно от выхода модели.

На основе таблиц этих материалов реализован [профиль author-semitic](../../../docs/LANGUAGE-PROFILES.md): явный набор допустимых форм применяется до декодирования всех трёх моделей. Сам исходный текст автоматически не исполняется. Текстовые правила замены звуков, ожидаемые слова и выводы о языке не следует выдавать за распознанные из аудио данные. Профиль Allosaurus имеет [другой формат](../../../README-profiles.md).

## Границы проверки

При сохранении проверяются наличие материалов, побайтовые контрольные суммы, ссылки и регистрация этой страницы. Библиография и историко-лингвистические выводы исходных файлов не проходили независимую проверку.

В самих материалах есть расхождения: шаблоны упоминают VI–VIII века н. э., а отчёт — VI век до н. э. при обсуждении спирантизации. Отчёт также прямо отмечает, что некоторые предложенные особенности не описаны в приведённой литературе. Поэтому материалы сохраняются как авторские гипотезы; в подтверждённую [методику](../../../docs/METHODOLOGY.md) эти положения не перенесены.
